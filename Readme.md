Мы представляем платформу -агрегатор данных по промышленным объектам Москвы. 
Данная платформа является дополнением для анализа промышленных предприятий Москвы и улучшения коммуникаций между департаментом и промышленным сектором. 
Менеджерам компании предоставляется упрощенная схема предприятия для оперативного реагирования на события. 
Они получают доступ к детальному плану загруженных участков производства и аналитике на основе данных, 
собранных со всех объектов предприятия, что значительно сокращает время принятия решения.



Стек решения: Для MVP: Python, Django, HTMX, HTML + CSS + JS +Bootstrap 5, Postgresql 14.
